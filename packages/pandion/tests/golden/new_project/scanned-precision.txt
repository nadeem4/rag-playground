# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

Every step in this pipeline runs on your computer, so it needs no API key.

=== pipeline.yaml
path: ./pandion-index
index:
  parse:
    use: docling
    do_ocr: true
    do_table_structure: true
    table_mode: fast
    content_layers:
    - body
  clean:
  - use: dedupe_blocks
    scope: near
    similarity: 0.95
  chunk:
    use: layout_blocks
    max_tokens: 400
    keep_tables_whole: true
    heading_context: true
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: BAAI/bge-reranker-v2-m3
    top_k: 5
answer:
  use: search
  top_k: 5
