# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

A step in this pipeline calls a model through an API, so it needs a key. Set ANTHROPIC_API_KEY in your environment before you run it. Never write a key into a file in this folder.

=== pipeline.yaml
path: ./pandion-index
categories:
  scanned:
    name: Scanned PDFs
    template: scanned
    parse:
      use: docling
      do_ocr: true
      do_table_structure: true
      table_mode: fast
      content_layers:
      - body
    clean:
    - use: dedupe_blocks
      scope: near
      similarity: 0.95
    chunk:
      use: layout_blocks
      max_tokens: 400
      keep_tables_whole: true
      heading_context: true
route:
- category: scanned
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: BAAI/bge-reranker-v2-m3
    top_k: 5
answer:
  use: chat
  model: claude-sonnet-5
  max_chunks: 5
