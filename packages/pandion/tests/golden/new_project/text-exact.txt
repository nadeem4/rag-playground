# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

Every step in this pipeline runs on your computer, so it needs no API key.

=== pipeline.yaml
path: ./pandion-index
categories:
  text:
    name: Text documents
    template: text
    parse:
      use: pdfium
      join_lines: true
    clean:
    - use: header_footer_strip
      min_page_ratio: 0.5
    - use: dedupe_blocks
    chunk:
      use: sentence_window
      sentences_per_chunk: 5
      overlap_sentences: 1
route:
- category: text
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    dense_weight: 1.0
    bm25_weight: 2.0
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: cross-encoder/ms-marco-MiniLM-L-6-v2
    top_k: 5
answer:
  use: search
  top_k: 5
