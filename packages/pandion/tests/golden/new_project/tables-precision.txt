# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

Every step in this pipeline runs on your computer, so it needs no API key.

=== pipeline.yaml
path: ./pandion-index
categories:
  tables:
    name: Reports with tables
    template: tables
    parse:
      use: docling
      do_table_structure: true
      table_mode: accurate
      do_ocr: false
      content_layers:
      - body
    clean:
    - use: dedupe_blocks
    chunk:
      use: layout_blocks
      max_tokens: 400
      keep_tables_whole: true
      heading_context: true
route:
- category: tables
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: BAAI/bge-reranker-v2-m3
    top_k: 5
answer:
  use: search
  top_k: 5
