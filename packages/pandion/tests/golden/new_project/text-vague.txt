# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

A step in this pipeline calls a model through an API, so it needs a key. Set ANTHROPIC_API_KEY in your environment before you run it. Never write a key into a file in this folder.

=== pipeline.yaml
path: ./pandion-index
categories:
  text:
    name: Text documents
    template: text
    parse:
      use: pdfium
      join_lines: true
    clean:
    - use: header_footer_strip
      min_page_ratio: 0.5
    - use: dedupe_blocks
    chunk:
      use: sentence_window
      sentences_per_chunk: 5
      overlap_sentences: 1
route:
- category: text
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  rewrite:
    use: llm_rewrite
    model: claude-haiku-4-5
    style: document words
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: BAAI/bge-reranker-v2-m3
    top_k: 5
answer:
  use: search
  top_k: 5
