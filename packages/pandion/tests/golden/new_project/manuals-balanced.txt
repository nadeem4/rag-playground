# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

Every step in this pipeline runs on your computer, so it needs no API key.

=== pipeline.yaml
path: ./pandion-index
categories:
  manuals:
    name: Manuals and guides
    template: manuals
    parse:
      use: docling
      heading_hierarchy: true
      do_table_structure: true
      table_mode: fast
      do_ocr: false
      content_layers:
      - body
    clean:
    - use: dedupe_blocks
    chunk:
      use: layout_blocks
      section_level: 4
      max_tokens: 512
      keep_tables_whole: true
      heading_context: true
route:
- category: manuals
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  search:
    use: hybrid_rrf
    top_k: 20
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: cross-encoder/ms-marco-MiniLM-L-6-v2
    top_k: 5
answer:
  use: search
  top_k: 5
