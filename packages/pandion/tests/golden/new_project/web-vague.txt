# project

This folder runs a Pandion retrieval pipeline on your own documents. The pipeline is in `pipeline.yaml`.

A step in this pipeline calls a model through an API, so it needs a key. Set ANTHROPIC_API_KEY in your environment before you run it. Never write a key into a file in this folder.

=== pipeline.yaml
path: ./pandion-index
categories:
  web:
    name: Web pages
    template: web
    parse:
      use: docling
      content_layers:
      - body
    clean:
    - use: drop_matching
      mode: regex
      pattern: ^\s*(we use cookies|this (web)?site uses cookies|accept (all )?cookies|manage
        (cookie|preferences))
    - use: drop_matching
      mode: regex
      pattern: ^\s*(home|about|contact|menu|skip to content|sign in|log in)\s*$
    - use: drop_matching
      mode: regex
      pattern: ^\W*(copyright|all rights reserved|privacy policy|terms of (use|service))
    - use: dedupe_blocks
    chunk:
      use: markdown_header
      max_tokens: 400
route:
- category: web
index:
  embed:
    use: qwen3-embedding-0.6b
  store:
    use: lancedb
    metric: cosine
    build_fts: true
retrieve:
  rewrite:
    use: llm_rewrite
    model: claude-haiku-4-5
    style: document words
  search:
    use: hybrid_rrf
    top_k: 30
    rrf_k: 60
    query_expansion: none
  rerank:
  - use: cross_encoder
    model: BAAI/bge-reranker-v2-m3
    top_k: 5
answer:
  use: search
  top_k: 5
